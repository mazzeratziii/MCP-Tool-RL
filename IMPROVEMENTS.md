# Улучшения системы выбора инструментов

**Дата:** 2026-05-14  
**Проблема:** Система выбирала неправильные инструменты (например, "4Bro - 1337X.GetBroCoins" для запроса "2 + 234")

## Реализованные решения

### ✅ 1. Порог релевантности (MIN_SEMANTIC_THRESHOLD = 0.70)
**Файл:** `src/rl/train_grpo.py`  
**Изменение:** Метод `_get_tools_state` теперь фильтрует инструменты с semantic score < 0.70

**Эффект:** Исключает явно нерелевантные инструменты из рассмотрения

### ✅ 2. Усиление semantic_bias (3.0 → 5.0)
**Файлы:** 
- `src/rl/train_grpo.py` (профили desktop и laptop)
- `src/rl/reward_functions.py` (добавлен штраф за низкую семантику)

**Изменения:**
- `semantic_bias` увеличен с 3.0 до 5.0 в обоих профилях
- Добавлен штраф `-0.5 * (0.6 - semantic_score)` для инструментов с score < 0.6

**Эффект:** Модель сильнее учитывает семантическую релевантность при выборе

### ✅ 3. Fallback инструменты
**Файлы:**
- `src/config.py` (добавлены 2 новых инструмента)
- `src/environment/mcp_environment.py` (обработчики для fallback инструментов)

**Добавленные инструменты:**
1. **Calculator.Evaluate** - для математических выражений
   - Автоматически определяет математические запросы
   - Вычисляет результат безопасно (только базовые операции)
   - Высокая награда при правильном использовании

2. **General.NoToolNeeded** - для простых вопросов
   - Для приветствий, благодарностей, простых объяснений
   - Используется когда внешний API не нужен

**Эффект:** Система может корректно обрабатывать запросы, не требующие специализированных API

### ✅ 4. Дообучение ретривера
**Файл:** `src/retriever/finetune_retriever.py`

**Изменения:**
- Добавлено 30+ синтетических примеров для математики и простых запросов
- Примеры автоматически включаются в обучение ретривера

**Эффект:** Улучшенное качество семантического поиска для базовых запросов

## Troubleshooting

**Проблема:** Ретривер не находит fallback инструменты  
**Решение:** Убедитесь, что запустили `python src/retriever/finetune_retriever.py` после добавления синтетических примеров

**Проблема:** Модель всё ещё выбирает неправильные инструменты  
**Решение:** 
1. Увеличьте `MIN_SEMANTIC_THRESHOLD` до 0.75
2. Увеличьте `semantic_bias` до 7.0
3. Обучите модель дольше (50-60 эпох)

**Проблема:** Out of memory при обучении  
**Решение:** Уменьшите `train_set_size` в laptop профиле (600 → 400)
