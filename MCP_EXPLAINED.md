# Что такое MCP в этом проекте

MCP-инструменты предоставляют внешние возможности через структурированный tool interface.

В проекте MCP используется как целевая абстракция выбора инструмента:

- пользователь отправляет запрос;
- система извлекает candidate tools;
- selector ранжирует инструменты по functional fit и execution conditions;
- environment либо эмулирует вызов, либо использует hybrid MCP call.

Фокус исследования — не реализация самого MCP-протокола, а выбор подходящего инструмента при нестабильных сетевых условиях.
